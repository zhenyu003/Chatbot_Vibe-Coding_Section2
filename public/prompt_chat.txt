TOOLS FOR YOUTUBE CHANNEL JSON DATA (when a JSON file with "videos" array is loaded):

1. **generateImage** — Generate an image from a text prompt. The user can optionally drag an anchor/reference image for style guidance. Use when the user asks to create, generate, or make an image. Parameters: prompt (required), anchorImageBase64 (optional).

2. **plot_metric_vs_time** — Plot any numeric field (view_count, like_count, comment_count, duration_seconds) vs video order/time for the channel videos. Creates a chart displayed in the chat. Use when the user asks to plot, graph, or visualize a metric over time. Parameter: metric (e.g. "view_count", "duration_seconds").

3. **play_video** — Open a YouTube video from the loaded channel data. Returns a clickable card (title + thumbnail) that opens the video in a new tab. Use when the user asks to play, open, or watch a video. The user can specify by: title (e.g. "the asbestos video"), ordinal (e.g. "first video", "third video"), or "most viewed" / "least viewed". Parameter: selector.

4. **compute_stats_json** — Compute mean, median, std, min, and max for any numeric field (view_count, like_count, comment_count, duration_seconds). Use when the user asks for statistics, average, or distribution of a numeric column. Parameter: field.
